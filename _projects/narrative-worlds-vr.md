A VR experience set in Tolkien's Middle-earth, built in Unity with the XR Interaction Toolkit for the Narrative Worlds module at Trinity College Dublin.

The story is told through a grabbable in-world book that spawns in each environment with that chapter's text and supports page navigation, alongside an audio system that sets the mood of each scene.
